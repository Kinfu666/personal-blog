# 完整功能驗收清單

本清單對應 SPEC v1.0。勾選代表開發時已透過測試、HTTP 或實際瀏覽器驗證；使用者可在 VS Code 終端機啟動後依步驟重驗。

## 啟動與帳號

- [x] `java -jar target/personal-blog.jar --app.data-dir=./驗收資料` 在空目錄建立 DB、表、uploads 與 admin，無需外部資料庫。
- [x] 預設只在 `127.0.0.1:8080` 監聽；demo 使用 `admin / DemoBlog!2026`。
- [x] 全新資料有 4 分類、10 標籤、12 發布文章、3 草稿、6 PNG；文章具摘要、分類、標籤與完整技術內容。
- [x] 停止後以相同資料位置啟動，帳號、文章、分類、標籤、圖片與變更保留，無重複初始化。
- [x] 種子初始化中途失敗不寫成功標記，資料列及圖片回滾；排除故障可再次成功初始化。
- [x] `app.seed.enabled=false` 不載入示範文章；prod 無合法初始密碼時拒絕首次初始化。

## 前台 F01–F04

- [x] 首頁只有已發布文章，每頁六篇；標題、摘要、日期、分類、標籤皆存在。
- [x] 發布時間新到舊；同時間依 ID 降冪，第二頁沒有重複或漏掉同時間的文章。
- [x] 點擊標題進入全文；標題、清單、程式碼、連結、本地圖片可正常顯示。
- [x] 草稿 ID 與不存在 ID 都得到 HTTP 404，友善頁面不暴露草稿內容。
- [x] 關鍵字可命中標題、摘要或內容；分類、標籤與關鍵字可同時篩選。
- [x] 翻頁保留 q／category／tag；不存在結果有提示與清除條件入口。
- [x] 關於本站無捏造履歷，說明展示用途與 AI 輔助內容；導覽、頁尾可使用。
- [x] 1440px 桌面與 390px 手機 viewport 實際載入，首頁、全文與後台均無水平溢位。

## 登入與總覽 A01、A08

## 文章 A02–A05

- [x] 列表可關鍵字與狀態篩選，並分頁；新增、編輯、刪除各路由有實際資料庫效果。
- [x] 刪除按鈕顯示確認視窗；刪除使用 POST，GET 不會刪除資料。
- [x] 標題必填且最多150字、摘要必填且最多300字、內容必填且最多50000字。
- [x] 必選一個存在的分類，標籤可零至多個；不存在關聯不會被安靜忽略。
- [x] 後端驗證失敗回到表單，保留輸入與欄位提示；成功採 PRG。
- [x] 草稿可發布、發布可撤回；首次發布設定時間，編輯發布文章保留時間，撤回清空，重發重新計時。
- [x] 即時預覽透過伺服器共用 renderer；上傳圖片後可插入游標位置並預覽。

## 圖片與安全 A07、非功能

- [x] 有效 JPEG、PNG、WebP 可解碼上傳；清單顯示縮圖與可複製的 Markdown。
- [x] MIME、格式簽章、實際解碼與尺寸都驗證；拒絕 HTML 偽裝、MIME 不符、損壞格式與超大檔案。
- [x] 單張最多5 MiB，單邊最多10000px、總像素最多2500萬；以 UUID 及允許副檔名儲存。
- [x] 原始檔名含 `../` 不會成為儲存路徑；非受控檔名讀取遭拒。
- [x] 訪客只能取得已發布文章實際引用的圖片，草稿與未引用圖片不可公開。
- [x] 文章撤回後圖片新請求立即失去公開權限；回應有正確 Content-Type、nosniff 與 no-store。
- [x] 刪除前以 Markdown AST 檢查圖片引用；草稿也計入，純文字／程式碼／一般連結不誤判。
- [x] 上傳與刪除交易回滾時補償檔案；啟動時修復 `.deleted` 與孤兒檔案。
- [x] Markdown 跳脫 raw HTML、清理危險協定／屬性、拒絕外部圖片與路徑穿越；正常 Markdown 保留。
- [x] 預覽與上傳失效請求回傳一致 JSON 訊息；一般403、404、500有友善頁，500附可追蹤編號。
- [x] Bootstrap、JavaScript、CSS與選單SVG均本地載入；瀏覽器未產生外部資源請求或 CSP 違規。

## 建議使用者手動驗收順序

1. 用全新 `app.data-dir` 啟動，閱讀首頁第一／二頁與含圖全文，組合三種搜尋條件。
2. 登入總覽，比對 15／3／4／10 數字；新增測試分類與標籤，測試空白、重複與更新。
3. 新增文章並選取分類／標籤，先存草稿確認前台找不到；發布後確認出現。
4. 編輯 Markdown，加入清單、程式碼、連結；上傳圖片插入，確認即時預覽與全文一致。
5. 撤回文章，登出或用無痕視窗確認全文及其專用圖片不可讀。
6. 嘗試刪除仍被引用的分類、標籤、圖片；移除引用後再刪除，確認提示與結果。
7. 修改或刪除示範文章後停止再啟動，確認沒有復原或重複載入。
